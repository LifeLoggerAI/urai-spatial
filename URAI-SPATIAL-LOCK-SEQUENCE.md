# 🔥 10-Minute Spatial Stability Sweep

Do this exactly in order.

No tweaking while observing.

Just observe and write notes.

---

## 1️⃣ Hard Refresh x10

* Cmd/Ctrl + Shift + R ten times.
* Watch mount carefully.

Look for:

* Flash
* Background color mismatch
* Camera micro snap
* Orb brightness spike
* Starfield pop-in

If any of those happen even once → that’s Priority #1.

---

## 2️⃣ Idle Test (2 minutes)

Hands off mouse.
No interaction.

Look for:

* Camera drift
* Orb brightness fluctuation
* Twinkle aggression
* Subtle animation loop seams

If it feels “alive” in a distracting way → reduce motion.

---

## 3️⃣ Mouse Parallax Check

Move mouse slowly corner to corner.

Ask:

* Is this subtle?
* Or does it feel like a demo effect?

If it feels like an effect → reduce by 30–50%.

---

## 4️⃣ Zoomed-Out Noise Test

Squint at the screen.

If it looks busy → star density is too high.

If your eye doesn’t know where to rest → too many anchors.

You want:
Orb = focal gravity.
Everything else = secondary.

---

## 5️⃣ Emotional Check

Ask one question:

Does this feel calm?

If the answer is:

* “Kind of”
* “Almost”
* “Pretty much”

Then it’s not calm enough.

Calm should feel undeniable.

---

## 6️⃣ Performance Check

Open Chrome task manager.

Let idle for 3 minutes.

* Memory climbing?
* GPU spikes?
* Fans ramping?

If yes → animation intensity too high.
