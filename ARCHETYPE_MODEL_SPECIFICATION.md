# Archetype Engine: Mathematical Specification (Version 0.1)\n\n**Purpose:** To define the precise, implementable mathematical model for the Archetype Evolution Engine. This document translates the conceptual framework into a formal specification, ensuring that all calculations adhere to the ethical principles outlined in the `PSYCHOLOGICAL_RISK_AUDIT.md`.\n\n---\n\n## **I. Core Components & Variables**\n\n### **1. Input Data: The `EmotionVector`**\n\n*   The fundamental unit of input is a daily `EmotionVector` ($E_v$), captured implicitly.\n*   $E_v = \\{valence, arousal, agency\\}$\n    *   `valence`: A float from -1.0 (negative) to 1.0 (positive).\n    *   `arousal`: A float from 0.0 (calm) to 1.0 (energetic).\n    *   `agency`: A float from 0.0 (passive) to 1.0 (proactive).\n*   This vector is a simplified, non-clinical representation of emotional state.\n\n### **2. Archetype Definitions: The `ArchetypeMatrix`**\n\n*   Each of the core Seasonal Archetypes (e.g., Explorer, Protector, Dormant) is defined by a target `EmotionVector` point in 3D space. This forms a static `ArchetypeMatrix` ($A_M$).\n*   Example Definitions:\n    *   $A_{Explorer} = \\{valence: 0.7, arousal: 0.8, agency: 0.9\\}$\n    *   $A_{Protector} = \\{valence: 0.1, arousal: 0.6, agency: 0.7\\}$\n    *   $A_{Dormant} = \\{valence: 0.0, arousal: 0.1, agency: 0.2\\}$\n    *   *(These are illustrative and require tuning)*\n\n---\n\n## **II. Layer 1: Seasonal Archetype Calculation (Short Cycle)**\n\n### **1. Daily Archetype Affinity Score**\n\n*   On any given day $d$, the user has a raw `EmotionVector` $E_{v(d)}$.\n*   The affinity for each archetype $A_i$ in the `ArchetypeMatrix` is calculated as the inverse of the Euclidean distance between the user\'s vector and the archetype\'s target vector.\n*   $Affinity(A_i, d) = 1 - \\tanh(||E_{v(d)} - A_i||)$\n    *   We use the hyperbolic tangent to create a normalized score between 0 and 1 with a smooth falloff. A perfect match yields an affinity of 1; a distant vector approaches 0.\n\n### **2. 90-Day Weighted Moving Average**\n\n*   The dominant Seasonal Archetype is determined not by a single day, but by a 90-day weighted moving average of affinity scores.\n*   Let $S_i(t)$ be the smoothed score for archetype $A_i$ at time $t$.\n*   $S_i(t) = \\frac{\\sum_{d=t-89}^{t} w_d \\cdot Affinity(A_i, d)}{\\sum_{d=t-89}^{t} w_d}$\n*   The weight $w_d$ is a decay function, giving more importance to recent days. We use an exponential decay:\n    *   $w_d = e^{-\\lambda(t-d)}$, where $\\lambda$ is the decay constant (e.g., $\\lambda = 0.05$). This makes the last ~2 weeks most influential.\n\n### **3. Dominant Seasonal Archetype**\n\n*   The dominant archetype for the current season is simply the one with the highest smoothed score:\n*   $Archetype_{Seasonal} = \\arg\\max_{A_i}(S_i(t))$\n*   **This result is never shown directly to the user.** It is a signal for the Visual and Narrative layers.\n\n---\n\n## **III. Layer 2: Era Archetype Detection (Medium Arc)**\n\n*   This layer analyzes the sequence of dominant *Seasonal Archetypes* over 1-3 year periods.\n\n### **1. Quarterly Archetype Frequency**\n\n*   Every quarter (90 days), the system calculates the frequency distribution of the dominant archetypes during that period.\n*   $Q_f = \\{A_{Explorer}: 0.4, A_{Builder}: 0.3, ...\\}$\n\n### **2. Era Clustering**\n\n*   The system stores a rolling history of the last 12 quarterly frequency distributions ($Q_{f(t-11)}$ to $Q_{f(t)}$).\n*   It uses a K-means clustering algorithm (or similar unsupervised learning method) on this sequence of vectors to identify recurring patterns (Era Archetypes).\n*   Example Cluster Centroids (Learned over time):\n    *   **Era "Expansion":** High frequency of Explorer, Builder.\n    *   **Era "Consolidation":** High frequency of Protector, Integrator.\n*   **This serves the `PSYCHOLOGICAL_RISK_AUDIT.md`:** The clusters are not pre-defined but emerge from the user\'s own data, preventing the system from imposing external narratives.\n\n### **3. Narrative Trigger**\n\n*   When the sequence of quarterly vectors for the last 2-3 years shows a high cosine similarity to a known Era cluster centroid, a narrative event is triggered for the Companion to subtly remark upon (e.g., "This era has been about widening your world.").\n\n---\n\n## **IV. Layer 3: Lifetime Tendency Analysis (Long Arc)**\n\n*   This layer operates on the longest time scales (5-10+ years) and analyzes the dynamics *between* Eras.\n\n### **1. Calculating Meta-Variables**\n\n*   **Volatility ($\sigma^2$)**: The variance in the dominant archetype over a multi-year period. A high volatility indicates frequent seasonal shifts.\n*   **Periodicity ($P$):** The system uses a Fourier transform on the long-term affinity scores ($S_i(t)$) for each archetype to detect recurring cycles (e.g., a return to the "Explorer" state every ~2 years). This is the mathematical basis for "Pattern Return Interval."\n*   **Reinvention Event ($R_{event}$):** A Reinvention Event is flagged when a new Era cluster is formed that has a low cosine similarity to all previously established Era centroids. **This explicitly canonizes pattern-breaking as a key, positive event**, fulfilling a core requirement of the risk audit.\n\n### **2. The Lifetime Tendency Signature**\n\n*   The "Identity Signature" is a vector composed of these long-term meta-variables:\n*   $Signature_{Lifetime} = \\{\\sigma^2, P_{dominant}, R_{count}, ...\\}$\n*   This vector is **not** an archetype. It is a mathematical description of the user\'s unique rhythm of change.\n*   This signature vector directly controls the parameters of the "faint outer halo ring" in the Life-Map visualization (e.g., its pulse rate, color gradient, complexity), but is **never textualized**.\n
