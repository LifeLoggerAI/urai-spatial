# Privacy Feature Manifests

Status: draft scaffold

Every data-processing feature in this repository must have one manifest in this directory before privacy approval.

Each manifest must map:

- feature owner
- user-visible behavior
- collected data
- derived data
- inferred data
- consent tier
- retention behavior
- export behavior
- deletion behavior
- explanation behavior
- audit events
- vendor or processor impact

This directory is incomplete until every production feature has a corresponding manifest.
