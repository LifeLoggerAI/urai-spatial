# SPATIAL_LOCK: The Immutable Invariants

This document defines the immutable, non-negotiable, and foundational invariants of the URAI-Spatial experience. They are locked. They are the law. Any contribution that violates these invariants is, by definition, a bug.

## 1. The Sanctuary is Private

*   **1.1 Solitary Experience:** The user's spatial environment is, by default, a solitary and private experience.
*   **1.2 No Social Features:** There are no social features. No chat, no avatars, no presence indicators.
*   **1.3 Privacy by Default:** No user data is ever made public without explicit, ceremonial, and revocable consent, as defined in `URAI-STORYTIME_WORKFLOWS.md`.

## 2. Time is Sacred

*   **2.1 System-Controlled Pacing:** The pacing of memory replay is system-controlled.
*   **2.2 No User Pacing Controls:** There are no user controls for fast-forwarding, rewinding, or scrubbing through replays.
*   **2.3 Uninterruptible Replay:** Once initiated, a memory replay cannot be interrupted by other UI or spatial interactions.

## 3. Interaction is Focused

*   **3.1 Locked Vocabulary:** The user's interaction vocabulary is permanently locked to: "gaze," "select," and "exit."
*   **3.2 No Other Verbs:** There are no other verbs. No jumping, no running, no complex manipulations.

## 4. The Experience is Not a Game

*   **4.1 No Gamification:** There are no points, no scores, no leaderboards, no achievements, no streaks.
*   **4.2 Intrinsic Value:** The system does not reward or punish the user. The value of the experience is intrinsic and reflective, not extrinsic and competitive.

## 5. Consent is Ceremonial & Revocable

*   **5.1 Explicit Consent:** All actions that involve data sharing are initiated by the user and require explicit, ceremonial consent.
*   **5.2 Revocable Consent:** The user can revoke any consent at any time. Revocation is immediate and permanent.
