# Feedback To Roadmap Pipeline

Feedback is useful, but V1 patches must not become uncontrolled feature creep. This pipeline turns feedback into grouped evidence for later planning.

## Feedback Categories

- Privacy/trust.
- Onboarding confusion.
- Visual polish.
- Companion quality.
- Mobile usability.
- Accessibility.
- Performance.
- Feature request.
- Fundraising/supporter feedback.

## Priority Order

1. Privacy/trust.
2. App-breaking bugs.
3. Mobile usability.
4. Onboarding clarity.
5. Passport comprehension.
6. Companion usefulness.
7. Visual/audio polish.
8. New features.

## Rules

- Do not add features directly from one request.
- Group repeated requests.
- Validate against V1 scope.
- Defer roadmap items cleanly.
- Keep patch notes focused on shipped fixes, not speculative promises.

## Roadmap Handoff

For each grouped item, capture the category, evidence count, affected route or feature, privacy impact, and whether it belongs in V1 patching, private alpha, beta, or later roadmap.
