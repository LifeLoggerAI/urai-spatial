## Precedence rule

1. Live exact-head source and current product/canon authority.
2. Current exact-head runtime and literal-pixel evidence.
3. Current accessibility/privacy/security/truth constraints.
4. Current accepted references.
5. Reusable supporting references.
6. Historical provenance.

No historical screenshot, workflow, or document may defeat a newer explicit canon lock merely because it has a green receipt.

## Supersession receipt rule

When a stale document or receipt makes a claim contradicted by live authority, preserve it and create a successor/correction. Do not silently rewrite history to imply the old artifact was always correct.
