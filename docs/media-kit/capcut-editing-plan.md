# CapCut Editing Plan

Use this plan for founder demo clips, teaser posts, fundraiser updates, and launch walkthrough edits.

## Edit Flow

1. Import screen recordings.
2. Add a soft cinematic intro.
3. Add subtle captions.
4. Add heartbeat glow or orb pulse accents.
5. Add tagline reveal.
6. Add stretch goal flare variant for fundraiser versions.
7. Use calm ambient music.
8. Avoid aggressive transitions.
9. Confirm the sample-data disclosure appears in the edit.
10. Export final versions.

## Export Formats

- Vertical: 1080x1920.
- Landscape: 1920x1080.
- Square: 1080x1080.

## Caption Style

- Minimal.
- White or soft glow.
- No clutter.
- No long text blocks.
- Keep captions readable on mobile.

## Safety Pass

Before export, check for private data, browser tabs, notifications, debug UI, raw IDs, environment values, private Shadow content, private Legacy content, and risky medical or surveillance language.
