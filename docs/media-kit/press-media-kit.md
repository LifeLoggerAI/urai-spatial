# Press Media Kit

## Product Name

URAI

## One-Liner

> URAI is building a privacy-first spatial interface for memory, identity, reflection, focus, and personal direction.

## Founder

Adam Clamp

## Short Description

> URAI replaces flat dashboards with a symbolic spatial journey through Home, Ground, Life Map, Focus, Replay, Mirror, Passport, and Status. The current public experience uses sample data and fallback-safe behavior while production certification, authenticated persistence, selected provider assets, and physical-device proof remain separately gated.

## Current Evidence Boundary

- The canonical repository contains a substantial spatial web demo and release infrastructure.
- Public demonstrations use sample data.
- Route availability does not prove authenticated persistence, active providers, physical-device certification, or production certification.
- Claims must be rechecked against `STATUS.md`, `EVIDENCE.md`, `urai-tier1/src/data/launchTruth.ts`, and exact deployment receipts.

## Media Assets Needed

- Logo.
- App screenshots from an exact verified build.
- Founder photo approved for public use.
- Demo video with visible sample-data disclosure.
- Product one-pager.
- Privacy and permission summary.
- Verified demo or waitlist link.

## Press-Safe Claims

- Privacy-first design.
- Permission-first interaction.
- Spatial and symbolic reflection.
- User-controlled memory experience.
- Sample-data public demo.
- Evidence-gated production, provider, persistence, and device claims.

## Avoid

- Medical, diagnostic, treatment, or therapy-replacement claims.
- Lie detection, mind reading, emotional certainty, or surveillance framing.
- Claims that imply always-on monitoring.
- Claims of persistent personal memory without authenticated ownership, deletion, export, revocation, and live evidence.
- Production-certified, provider-active, or device-certified language without exact receipts.
- Investment-return, valuation, market-size, IP-ownership, or regulatory guarantees.

## Required Demo Note

> This demo uses sample data. Some capabilities use fallback-safe behavior and remain production-certification pending.
