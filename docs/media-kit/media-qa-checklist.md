# Media QA Checklist

Run this checklist before publishing any URAI launch media.

- No private data.
- No debug UI.
- No raw IDs.
- No environment variables.
- No browser console.
- No real Shadow content.
- No real Legacy content.
- No medical claims.
- No therapy-replacement claims.
- No diagnosis claims.
- No lie-detection claims.
- No surveillance language.
- Demo sample disclosure visible.
- Captions readable.
- Mobile crops good.
- Desktop crops good.
- Audio levels safe.
- Reduced-motion friendly where relevant.
- Browser bookmarks, email, tabs, and notifications hidden or blurred.
- No broken media placeholders.
- No raw Firebase, admin, or environment screens in public assets.

## Required Disclosure

"This demo uses sample data."
