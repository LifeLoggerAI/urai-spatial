# Demo GIF / Loop Plan

Use short, privacy-safe loops for the launch site, fundraiser page, social posts, and investor follow-ups.

## Short Loops

- Orb breathing on Genesis.
- Sky tap to Life Map.
- Ground bloom opening.
- Passport toggle.
- Mirror reflection card.
- Export scroll preview.

## Loop Rules

- Keep loops 3 to 8 seconds.
- Use sample data only.
- Do not show private data.
- Do not show debug UI.
- Do not show browser chrome unless intentionally cropped.
- Use smooth start and end frames.
- Optimize file size before publishing.
- Keep the sample-data disclosure visible when the loop is used in a longer page context.

## Recommended Deliverables

- MP4 for site performance.
- GIF only when platform requirements demand it.
- Vertical crop for stories.
- Square crop for social grid previews.
