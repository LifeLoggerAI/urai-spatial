Parent authority: LifeLoggerAI/urai-storytime#27

## Purpose

Deliver approved FINITE TIME masters and chapters through the continuous URAI world while preserving privacy, provenance, accessibility, performance, demo disclosure, and user control.

## Delivery modes

- private project threshold
- flat-screen feature playback
- chapter playback in Replay
- Life Map / Legacy anchors
- Focus entry and return
- Mirror reflection derivative
- Passport ownership/provenance view
- Consent Sanctuary controls
- clearly labeled AR/VR/XR reconstruction derivatives

The linear feature and interactive derivatives are distinct products and must never be falsely presented as identical.

## Runtime manifest requirements

- project, chapter, scene, and asset versions
- exact content hashes and canonical source identity
- approval and accessibility versions
- reconstruction/provenance disclosure
- privacy and audience state
- captions, transcript, audio description, haptic cues
- reduced-motion, sensory-safe, keyboard, screen-reader, mobile, low-quality, offline, and fallback behavior
- entry, return, unwind, and continuity state

## Public boundary

Signed-out or public users never mount private family source media or sensitive records. Public demos use explicitly disclosed approved samples or redacted derivatives.

## Verification

Retain exact-head desktop/mobile video and screenshots, console/network records, frame audits, transition and return proofs, performance budgets, accessibility results, fallback/offline checks, and rollback evidence.

## Promotion gate

No public publication occurs until the parent feature, factual, rights, family, dignity, accessibility, and release gates explicitly pass.

This contract does not claim the proof chapter or feature has been integrated or released.
