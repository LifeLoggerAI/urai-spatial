## Runtime authority

Memory World extends the existing Lived World, Replay and Captured Reality systems. It does not replace them.

The current runtime path is:

```text
Life Map -> Focus -> Replay
  -> source-reviewed Captured Reality when authorized and available
  -> otherwise bounded Memory World contextual template
  -> Return -> Replay / Focus / Life Map continuity
```

The bounded template route is `/spatial/memory-world`.

## Truth boundary

Template geometry is T4 CONTEXT_TEMPLATE and is always non-autobiographical. Interpretive atmosphere is T6. Neither is presented as recorded history.

Captured Reality remains separately governed. A Gaussian splat maps to T2 SPATIALLY_RECONSTRUCTED when backed by recorded evidence and source review. It never becomes T0 SOURCE_CAPTURED merely because it looks photoreal.

Unknown place context resolves to a neutral memory threshold rather than inventing culture, architecture, religion, class, occupation or household structure.

## Hybrid representation

The runtime plan supports Gaussian splat, mesh, procedural, digital-human, audio and metadata representations. Captured appearance does not establish collision or navigation safety.

Until a verified interaction/navigation proxy exists, navigation remains bounded orbit/zoom rather than embodied walking.
