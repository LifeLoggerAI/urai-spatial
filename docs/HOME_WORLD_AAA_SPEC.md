# Home World AAA Production Spec

## Intent

`/` and `/home` are the URAI Spatial Genesis Home World. They should feel like the first private sanctuary where the user steps inside their own memory universe. The route must read as one authored scene: sky, horizon, terrain, subtle body presence, living orb, and grounded route portals.

## First three seconds

The user sees `Own your life. Step inside yourself.`, then the eye settles on the horizon, central presence, orb, and world portals. The page should not read as a SaaS card or dashboard.

## Systems

- Ground: curved sanctuary terrain, plinth, reflection, path lines, and diegetic portals.
- Sky: sparse memory ceiling, aurora haze, depth glow, and negative space.
- Horizon: clear vanishing point guiding the Life Map entry.
- Avatar: subtle embodied presence through aura, core, body glow, shadow, and reflection.
- Orb: one interactive companion that opens an in-world panel with real route choices.
- Motion: breathing, hover lift, restrained glow, and full reduced-motion support.

## Route wiring

Visible entries must link to real routes: `/life-map`, `/focus?memoryId=quiet-reset`, `/replay?memoryId=quiet-reset&manifestId=replay-recovery-thread`, `/mirror`, `/passport`, `/status`, `/privacy-controls`, `/unwind`, and `/ascent`.

## Production safety

The Home World must remain Next/static-export safe, use existing/procedural assets, avoid missing private assets, preserve keyboard focus states, keep contrast readable, and protect mobile performance.
