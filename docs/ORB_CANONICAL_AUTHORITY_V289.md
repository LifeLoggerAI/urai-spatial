# UrAi Orb — V289 Canonical Authority

Status: successor authority candidate layered on top of the active Home #1177 branch.

## Identity lock

The UrAi Orb is the grounded fractured mineral memory reliquary protecting an exposed, slowly living network of memory light.

It is not a sphere, glass object, portal, portal ring, holographic globe, planet, Memory Star, floating menu, generic AI icon, three-sphere fallback, anatomical heart, mini galaxy, or stock science-fiction reactor.

## Visual anatomy

Identity-critical structure:

1. multiple fractured opaque mineral shell plates;
2. a real dark cavity with readable negative space;
3. distributed branching internal memory filaments;
4. several irregular recessed memory nodes at different depths;
5. a localized fine internal memory field;
6. restrained local illumination that catches inward-facing shell surfaces;
7. subtle ground traces and convincing physical contact with terrain.

The system deliberately has no singular giant glowing nucleus and no transparent outer membrane.

## Material lock

Exterior materials remain graphite, ash, dark earth, and restrained aged mineral/bronze tones. Roughness stays high. Metalness stays extremely low. The Orb must not be upgraded into glass, crystal, chrome, resin, polished obsidian, wet plastic, or gemstone material language.

## State lock

State changes occur primarily inside the reliquary. The shell remains materially itself.

- dormant: muted earth-gold / deep cool grey-teal;
- idle: warm amber / desaturated teal;
- attention: clearer warm amber;
- listening: sea-glass teal / subdued blue-grey;
- thinking: restrained violet / cool blue;
- speaking: warm amber / earth warmth;
- guiding: ochre / sage;
- reflecting: lavender / slate;
- calming: sage / teal;
- privacy: controlled blue / cool teal;
- warning: muted terracotta / coral amber;
- transition: cool violet-blue.

State interpolation should be continuous and restrained. No RGB cycling or whole-shell warning coloration.

## Motion lock

The Orb is grounded. It does not bob, spin, hover, inflate like a heartbeat, or run a short obvious loop. Life is conveyed by very slow independent shell micro-drift, separate internal circulation, and gentle field breathing. Reduced-motion mode settles decorative transforms to the authored resting pose while preserving state color, geometry, semantics, and interaction.

## Interaction ownership

Visible reliquary geometry is visual-only. The invisible semantic/raycast proxy remains the pointer/touch interaction owner. Native semantic controls remain responsible for keyboard, focus, assistive-technology state, panel expansion/collapse, Escape behavior, and focus return.

## Ground ownership

The Orb must remain physically grounded through contact, shadow, lower-plate weight, and restrained root/mineral traces. It must not sit on a pedestal, glowing disc, portal marker, or invisible hover gap.

## Sky / Life Map boundary

The broad visible Home sky owns Home → Life Map. The Orb never owns the Life Map portal. During ascent the Orb remains in Home and recedes naturally as the camera leaves Ground scale behind.

## Orb versus Memory Star

The Orb is the singular persistent Home companion/reliquary. Memory Stars / memory manifestations are plural specific remembered experiences inside Life Map. They must not reuse the Orb shell, open-cavity structure, eight-plate silhouette, or Orb state system as their default visual identity.

## Performance contract

Identity-critical features never disappear: fractured silhouette, open cavity, visible internal network, major nodes, dark rough shell, state readability, and ground integration.

Scalable features include shell subdivision, tube radial/longitudinal segments, internal field point count, shadow quality, and micro-surface detail. Low-end fallbacks must remain the same reliquary identity and must never revert to a sphere.

## Explicitly retired visual semantics

The following words may appear only in historical/provenance discussion, never as current literal art direction:

- silver-blue glass;
- mirror glass;
- hover;
- orbiting sphere;
- secure ring;
- directional rim;
- portal lead;
- threshold stream;
- spherical membrane;
- central glowing nucleus.

## Evidence rule

Technical validity, green CI, or existence of a GLB is not visual acceptance. Current-head retained literal pixels must be opened and inspected. Successor commits must re-earn exact-head screenshots, accessibility/performance evidence, independent review where required, governance, and Gold-Master status.
