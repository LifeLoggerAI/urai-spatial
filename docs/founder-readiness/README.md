## Operating rule

Do not try to explain the entire URAI vision before the listener sees the product. Use this order:

1. State the human problem in one sentence.
2. Describe the product in plain language.
3. Show one coherent journey.
4. State exactly what is live versus still being built.
5. Ask for one next step.

The goal is not to make every person understand the full system immediately. The goal is to create enough clarity and curiosity for a focused follow-up.
