# URAI Real World Binary Handoff

The real-world model forge outputs binary GLB assets for six Council humans plus Council, Shadow, Mirror, and Legacy physical spaces. Camera framing contract is 5:4; geometry is authored in meters, Y-up.

This source branch remains the design/runtime bridge. Binary generation should run on an isolated child branch so unrelated commits cannot continuously cancel exact-head forge jobs.

Promotion remains gated on rendered route proof, device performance, reduced-motion/accessibility, provenance review, and final human rigging/animation where applicable.
