# URAI Privacy Location Rules

URAI treats location as private user context.

Required privacy modes:

- symbolic-only
- city-only
- approx-private
- exact-private
- exact-share-opt-in

Do not display exact addresses in Genesis mode.

Do not display raw latitude and longitude in Genesis mode.

Exact location stays private unless a future verified feature uses exact-share-opt-in with explicit user consent.
