# URAI UI Surface Inventory

Status: CANONICAL SURFACE BASELINE / PER-CONTROL SPEC EXPANDING

## Core spatial surfaces

### Home
World canvas; Orb semantic control; Ground/Life Map travel; movement help; privacy/status indicators; fallback/loading/error; mobile movement; reduced-motion/stimulation controls.

### Ground
World canvas; destination rail; proximity prompts; movement controls; direct destination controls; return Home; blocked/degraded/offline states.

### Life Map
World canvas; current location/overview; selected Memory Star context; layer/filter controls; search/command; timeline where enabled; Focus/Replay handoffs; direct semantic navigation; reduced-motion/no-WebGL.

### Focus
Selected-memory identity; source/provenance; contextual actions; continue to Replay; back; state/error/loading; accessibility controls.

### Replay
Evidence/context labels; playback/reconstruction controls; source availability; captions/description; hide/correct/history/save where current authority supports them; unwind/back.

### Mirror
Pattern selector; evidence/confidence/provenance; supporting fragments; accept/edit/reject; state disclosures; Replay/Passport/return.

### Shadow
Entry consent; load/intensity controls; evidence/context; return/re-seal; reduced stimulation; semantic fallback.

### Legacy
Archive navigation; selected continuity item; provenance; Life Map handoff; export/share controls only where authorized; Home return.

### Council
Participant selection; speaking/listening state; transcript/captions; cancel; role/context scope; Home/Mirror/Passport handoffs.

### Rituals
Invitation; skip/cancel; one action; timing/silence state; completion; return; sensory settings.

### Emotional Weather
State explanation; evidence/provenance; correction; privacy; reduced stimulation; place context; unavailable/sample disclosures.

### Possible Futures
Assumption editor; branch list; selected branch; comparison; provider/manual disclosure; no ranking; return.

### Passport
Identity/context; consent categories; local/private/shareable state; revoke/change; recent-auth/locked state; physical Home object semantic equivalent.

## Universal state requirements

Every interactive surface defines:
default, hover where pointer exists, focus, selected, disabled, loading, success, warning, error, empty, offline, permission-limited and destructive confirmation where applicable.

Controls must adapt to pointer, touch, keyboard and future controller/XR input without changing underlying authority.
