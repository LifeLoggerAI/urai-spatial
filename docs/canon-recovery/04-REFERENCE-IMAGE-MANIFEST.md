## Accepted/rejected/superseded rule

A reference may be:
- ACCEPTED only for its exact authority/head/state;
- CANDIDATE;
- REQUIRED/MISSING;
- REJECTED;
- SUPERSEDED;
- PREDECESSOR HEAD;
- CONCEPT ONLY.

Acceptance never transfers automatically across a changed implementation head.
