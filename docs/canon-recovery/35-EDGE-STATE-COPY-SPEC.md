# URAI Edge-State Copy Specification

Status: CANONICAL COPY REQUIREMENTS / FINAL WORDING MAY BE CENTRALIZED IN urai-content

This document defines what copy must communicate; it does not override later approved content-pack wording.

## Empty / no personal data

Intent:
- invite exploration without pretending UrAi already knows the user;
- disclose sample/demo content when shown.

Required meaning:
- “Your world starts empty by design.”
- user may add/import/connect only by choice;
- examples/sample memories are clearly labeled.

Prohibited:
- fabricated personalized insight;
- “we noticed” when no evidence exists.

## Permission denied

Required meaning:
- what was requested;
- why it helps;
- what still works without it;
- how to change the permission later.

Tone:
- neutral;
- no guilt;
- no dark patterns.

## Offline

Required meaning:
- current offline/local state;
- which actions remain available;
- which actions will sync later;
- whether anything is queued.

Never imply sync succeeded before it did.

## Resync/conflict

Required meaning:
- a conflict exists;
- what versions are being compared;
- user choice or safe deterministic merge behavior;
- no silent destructive overwrite.

## Source unavailable

Required meaning:
- source could not be reached or verified;
- no inferred substitute is presented as source truth;
- user may retry, continue without it, or inspect provenance.

## Emotional Weather unavailable

Required meaning:
- no permitted/adequate evidence is available;
- UrAi will not invent an emotional state.

## Mirror insufficient evidence

Required meaning:
- pattern cannot be supported strongly enough;
- show what evidence is present;
- invite correction/leave.

## Shadow entry

Required meaning:
- difficult/uncertain material may be present;
- entry is optional;
- sensory intensity may be reduced;
- immediate exit remains available.

No clinical or danger framing.

## Possible Futures

Persistent disclosure:
- scenarios are hypothetical;
- branches are unranked;
- they are not predictions or recommendations;
- assumptions can be edited.

## Replay truth states

Copy distinguishes:
- recorded evidence;
- supported context;
- interpretation;
- unknown/unavailable.

Never label generated reconstruction as recorded media.

## Passport / privacy

Required meaning:
- what is local/private/shareable;
- who can access;
- what permission is being changed;
- whether re-authentication is required;
- how to revoke/export/delete.

## Provider unavailable

Required meaning:
- provider-backed capability is unavailable;
- manual/local fallback if one exists;
- no claim that AI/provider action occurred.

## Subscription entitlement

Required meaning:
- current plan;
- feature entitlement;
- billing/provider truth;
- no hidden upgrade pressure.

Final pricing language must come from the current payment/entitlement authority, not historical copy.

## Accessibility controls

Controls should describe result, not implementation:
- Reduce motion
- Reduce visual intensity
- Captions
- Spoken descriptions / TTS where supported
- Haptics
- Audio
- High contrast / forced-color compatibility where applicable

## Destructive actions

Delete/export/revoke wording must state:
- scope;
- permanence/reversibility;
- affected data/surfaces;
- processing state;
- retained legal/audit exceptions where legitimately applicable.

No vague “clear everything” wording for scoped operations.
