# URAI Storyboard State Specifications

Status: SOURCE-DERIVED TEXT STORYBOARDS / VISUAL BOARDS STILL SEPARATE

These are state-accurate text storyboards built only where written canon is sufficiently explicit.

## Shadow

1. Entry threshold — user sees grounded mineral/blue-black realm and permanent return landmark.
2. Neutral exploration — bounded movement; no threat cues; uncertainty exists through softened distance, not horror.
3. Uncertainty focus — selected difficult material becomes locally clearer.
4. Contradiction focus — evidence and conflicting interpretations are surfaced without diagnosis.
5. High-load reduction — peripheral density, motion and sensory layers reduce.
6. Recovery — clarity returns gradually.
7. Exit — explicit Escape/return restores prior realm state.

Accessibility: reduced stimulation is first-class; no forced camera motion; semantic return always available; silence is valid.

## Legacy

1. Entry axis — clear archive orientation, shelves, reading tables and warm practical light.
2. Aisle exploration — user moves through bounded shelves with source-backed continuity objects.
3. Reading-table pause — selected item opens in a human-scale reflective context.
4. Continuity selected — provenance and uncertainty remain visible.
5. Life Map handoff — “Open continuity in Life Map.”
6. Return Home — user exits without losing context.

## Council

1. Chamber overview — six stable positions around central table.
2. Observer state — user sees who is available without cacophony.
3. Select participant — one role gains explicit visual ownership.
4. Listening — selected role receives question/context.
5. Speaking — one speaker at a time; captions/transcript authoritative.
6. Guiding gesture — restrained, role-consistent response.
7. Interrupt/cancel — immediate stop without penalty.
8. Travel — Home/Mirror/Passport handoff.
9. Mobile/reduced-motion/reduced-stimulation variants preserve role identity and readable speaker ownership.

## Ritual — Anniversary / Return Day

1. Eligibility detected from permitted source memory and spacing guard.
2. Optional invitation appears.
3. User accepts.
4. Silence-before interval.
5. One restrained symbolic callback/mark.
6. Optional voice/bloom only when allowed.
7. Silence-after interval.
8. Completion state.
9. Exact return to prior world state.

Cancel is available throughout.

## Ritual — Small Map / Threshold

1. Threshold context appears.
2. Optional low-load invitation.
3. User enters.
4. Long quiet/silence interval.
5. “Keep the map small” bounded action.
6. No voice and no bloom under current authority.
7. Completion.
8. Return.

## Possible Futures

1. Empty/manual entry — current path/requested change/constraint inputs.
2. One branch — scenario label persistent.
3. Three branches — equal hierarchy, stable non-value-ranked tokens.
4. Select branch A.
5. Select branch B.
6. Comparison — no winner/prediction treatment.
7. Edit assumptions.
8. Provider unavailable disclosure when applicable.
9. Return to origin.

## Mirror

1. Direct entry/load.
2. Evidence-aware chamber becomes inhabitable.
3. Pattern families appear only from authorized data/demo disclosure.
4. User selects one pattern.
5. Evidence, confidence, provenance and uncertainty become inspectable.
6. Reflection fragments and temporal context respond.
7. User may continue, correct/leave, or transition to Replay/Passport.
8. Partial/conflicting/permission-denied/offline/failure states remain truthful.
9. Reduced-motion/no-WebGL retain semantic access.

## Memory Star to Focus

1. Life Map overview contains small stellar photosphere/corona morphology.
2. Hover/near-cluster increases local readability without planet/collectible treatment.
3. Selected state establishes identity.
4. Departure begins from map.
5. Travel preserves world continuity.
6. Approach enlarges local stellar presence without becoming a magical artifact.
7. Arrival/pre-Focus handoff resolves selected-memory identity.
8. Focus assumes ownership.

## Personal Emotional Weather

1. No permitted evidence -> unavailable/quiet truthful state.
2. Evidence available -> localized personal-world atmosphere.
3. User inspects explanation/provenance.
4. User corrects/rejects interpretation if needed.
5. Visual atmosphere updates.
6. Audio/haptic density follows bounded sensory rules where enabled.
7. Reduced-stimulation preserves meaning with less density/motion.
8. History/persistence remains user-controlled.

## Storyboard production rule

A visual storyboard is accepted only after each frame is tied to:
- state ID;
- user action;
- system reaction;
- camera/transition;
- sound/haptic behavior;
- accessibility;
- privacy/truth state;
- resulting state;
- source authority;
- reference image ID where one exists.
