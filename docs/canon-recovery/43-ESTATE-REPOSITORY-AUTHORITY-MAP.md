## Key recovered data boundaries

### Privacy
Canonical historical Genesis categories include Audio, Location, Motion, Device Activity, Notifications, Calendar, Contacts, Health, Photos, and Passport, with privacy levels:
- localOnly
- privateCloud
- passportShareable

No transition to shareable state without visible user-controlled Passport action.

### Admin
Allowed: operational metadata, release evidence, aggregate analytics status, communications status, partner/admin records, feature flags, jobs, audit/governance evidence.
Forbidden absent separate approval: raw passive telemetry, audio, private transcripts, location trails, consumer identity vectors, unreviewed mental-health inference, secrets.

### Analytics
Bounded derived signals require explicit policy context. Raw prompts, journals, memories, transcripts, messages, audio, images/video, exact GPS, credentials, diagnoses/raw health records, private relationship content, or unauthorized values are prohibited.

### Content
Owns reusable packages, templates, narrator/replay manifests, localization, accessibility metadata, publication/provenance/rights metadata. It does not own private personal-memory source data.

### B2B
Uses privacy-reviewed summaries/status/adapters. It does not ingest raw consumer life telemetry.

### Storytime
V1 boundary is private adult/guardian-operated story creation/reading with age-aware safety, explicit consent, revocable sharing, honest provider/media gates, and complete data rights before broad launch.

## Repository-document authority caution

A repository README or roadmap proves product/system intent for that repo only to the extent it has not been superseded by a later accepted authority. It does not prove live deployment, provider activation, legal status, or visual acceptance.
