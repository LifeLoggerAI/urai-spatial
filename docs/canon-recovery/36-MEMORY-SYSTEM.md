# URAI Memory System Canon

Status: CORE CANON RECOVERED / FULL DATA CONTRACT STILL DISTRIBUTED

## Memory lifecycle

signal/media/manual entry
-> provenance
-> privacy classification
-> review/normalization
-> memory identity
-> chronology
-> semantic links
-> Memory Star
-> Focus
-> Replay
-> reflection/relationship/goal/ritual/legacy use.

## Memory object principles

A memory may carry sources, time/date certainty, people/relationship references, place if permitted, media, tags/themes, emotional/context signals, confidence/uncertainty, user corrections, privacy/vault state, and links to goals/decisions/chapters.

## Evidence hierarchy

Recorded media/source > supported context > interpretation/suggestion > unknown.

Replay and Mirror must preserve that distinction.

## User authority

The user may correct, hide, reclassify, link, unlink, archive, export or delete according to privacy/data-rights policy.

AI-derived links remain suggestions until user acceptance where the product requires it.

## Memory Stars

Memory Stars are spatial representations of memory identity, not planets, suns, collectibles or magical crystals.

## Private material

Sensitive memories may be visible as sealed architecture without exposing content. Shadow/private-vault entry remains explicit and cancelable.

## Long horizon

Memory supports chapters, annual/weekly review, Legacy, life films, relationship continuity, future reflection, and family/intergenerational features only with appropriate consent.
