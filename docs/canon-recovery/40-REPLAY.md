# URAI Replay Canon

Status: LAUNCH CORE / CINEMATIC SOURCE-TRUTH BOUNDARY LOCKED

## Purpose

Replay is a cinematic spatial reconstruction/experience of a selected memory.

It is not a generic video player, slideshow, projection wall, copy of Life Map or fabricated photoreal historical evidence.

## Truth layers

Replay distinguishes:
- recorded/source evidence;
- supported context;
- provisional interpretation;
- unknown/missing information.

When source media is absent, the system must not manufacture a fake record and present it as truth.

## Continuity

Focus -> Replay -> unwind -> Focus -> Life Map -> Home.

## Audio

Original/source audio only when actually available and authorized. Narration, reconstruction ambience and description must be clearly distinct from recorded source.

## Embodiment

Conventional desktop/mobile first person remains bodyless unless current realm-specific authority says otherwise. XR embodiment is a separate future/device concern.

## Accessibility

Playback/navigation, exit, captions, description/semantic context, reduced motion, source-missing state and no-WebGL equivalent must remain usable.

## Open work

Normalize current exact-head Gold Master captures, source/reconstruction provenance UI and final copy into one stable packet.
