Status: SOURCE-DERIVED TEXT STORYBOARDS / VISUAL FRAMES NOT YET ACCEPTED

## Shadow — SHADOW-001..009

1. Entry threshold: stable return landmark visible; explicit choice to enter.
2. Neutral exploration: grounded floor, readable depth, no threat cues.
3. Uncertainty focus: distant clarity reduces modestly; selected material gains readability.
4. Contradiction focus: evidence/context becomes inspectable; no accusation/diagnosis.
5. High-load safe reduction: effects simplify, motion/audio reduce.
6. Recovery/exit: clarity restores gradually; return remains obvious.
7. Reduced stimulation: static/low-density equivalent.
8. Mobile: same identity with direct navigation and safe controls.
9. No-WebGL: semantic summary, evidence, exit and privacy controls.

## Emotional Weather — WEATHER-001..018

Storyboard compares the SAME world/camera across states:
forming -> clear -> active -> heavy -> recovering midpoint -> recovering settled, then night, mobile, reduced-motion, reduced-stimulation, permission-limited, unavailable, disclosed sample, place-specific private/demo and semantic fallback.

User action is usually inspection/correction, not "trigger weather." System reaction must expose why the state changed and allow correction where applicable.

## Offline / Resync

1. Connected state.
2. Connection lost; no fake sync.
3. Local-safe actions identified.
4. Queued changes shown.
5. Reconnect.
6. Conflict if server/local diverge.
7. User chooses/reviews resolution where required.
8. Receipt confirms synced state.

## Permission Denied

1. User requests sensitive capability.
2. System blocks.
3. Explains required permission and why.
4. Offers settings/open demo/continue without capability.
5. No repeated coercive prompt.
6. Return to usable world.

## Empty / No Personal Data

1. Home/world exists but quiet.
2. No fake memories or emotional claims.
3. Explain what can be added/imported.
4. Optional disclosed sample.
5. User begins with manual reflection or permitted source.
6. World grows from real/explicitly sampled data.
