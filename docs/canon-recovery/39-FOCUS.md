# URAI Focus Canon

Status: LAUNCH CORE / GOLD-MASTER LINEAGE EXISTS

## Purpose

Focus is the approach and intimate arrival at one selected memory/Memory Star before Replay.

It is not a generic detail card, crystal pickup, separate unrelated dashboard or game-loot interaction.

## Required continuity

Life Map selected star
-> camera/travel approach
-> selected-memory identity preserved
-> localized place/memory phenomenon
-> evidence/context UI
-> Replay handoff
-> return to Life Map.

## Visual law

The memory manifestation belongs to the place/environment. Historical crystal/geode/shard/orb/ring/portal/cable/twig-like reads have been explicitly rejected in current visual lineage.

## Truth law

Focus must preserve what is known, inferred and unknown before entering Replay.

## Accessibility

Touch, keyboard, reduced motion, semantic selection/continue/back, no-WebGL truth and readable provenance are required.
