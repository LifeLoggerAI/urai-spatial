## Function traceability rule

Every function must eventually trace:

`canon -> user need -> UX -> UI -> data/source -> consent/privacy -> service -> asset -> test -> proof -> roadmap class`.

## Passive-signal function set recovered

Approved categories include voice tone/transcript, ambient tags, facial/emotional color signals where explicitly permitted, steps/motion, GPS/location snapshots, stillness, late-night scrolling, and quick-cancel interaction behavior. None may be treated as production-enabled solely because it appears in canon; each needs consent, source, storage/edge-processing, retention, deletion/export, uncertainty, and test evidence.

## Accessibility minimum matrix

Every spatial realm requires keyboard/touch/controller equivalence where applicable, reduced motion, nonvisual orientation, focus visibility, screen-reader semantics for non-canvas controls, sensory-intensity control, and a safe exit. Blind, Deaf/hard-of-hearing, ADHD/neurodivergent, and PTSD/TBI-sensitive paths must be explicit rather than inferred.
