# URAI Orb Canon

Status: CORE CANON / CURRENT VISUAL AUTHORITY PARTIAL

## Role

The Orb is the living-memory/heart/companion presence of UrAi. It is not a generic chatbot bubble, dashboard button, crystal, portal, pedestal ornament or follower that appears everywhere.

## Ownership

Current canon establishes Home as the principal Orb-owned realm. Life Map is explicitly Orb-free in several current movement/ownership authorities.

## Functional roles

Depending on permitted state, the Orb may orient, listen, reflect, speak, acknowledge, expose travel/semantic controls, communicate system state, or remain silent.

## Sensory rules

- authored material-led form;
- bloom is secondary;
- voice is consent/capability gated;
- captions/text equivalents remain;
- haptics are supplementary;
- silence is valid;
- no false speaking state before actual speech start.

## Privacy

The Orb cannot imply unavailable personal memory/context is present.

## Accessibility

Orb state cannot depend on animation/audio alone. Semantic controls remain available.

## Open work

Normalize all canonical Orb states, accepted exact-head references, state-specific copy, sound/haptic cues and no-WebGL equivalents into one stable manifest.
