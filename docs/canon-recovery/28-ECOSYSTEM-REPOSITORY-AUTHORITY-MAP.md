## Superseded generic roadmaps

The early `URAI_APP_MASTER_ROADMAP.md` centered Marketplace, Forum and generic Admin CRUD. It is retained as historical exploration and process guidance. It does not override the later spatial-memory product canon or current system-of-systems ownership map.

## Current cross-repo ownership principles

- one system of record per data/artifact type;
- privacy gates all personal-data processing;
- content owns reusable content packages, not private memory;
- Studio owns creative intent; Asset Factory executes asset jobs; Jobs owns async lifecycle;
- Analytics is aggregate/derived, not a raw personal-data lake;
- Admin is operational/governance, not a private-memory browser;
- B2B surfaces remain aggregate/privacy-reviewed;
- EWI proposes/normalizes external actions; provider/domain adapters dispatch only after policy.
