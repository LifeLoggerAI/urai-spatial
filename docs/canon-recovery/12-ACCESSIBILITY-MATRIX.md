# URAI Accessibility Matrix

Status: CANON RECOVERED / PER-REALM PROOF INCOMPLETE

## Canonical user needs

Recovered first-class accessibility intent includes:
- blind/low-vision: TTS, semantic UI, directional audio where helpful, nonvisual orientation;
- Deaf/hard-of-hearing: captions/visual equivalents, lip-read support where applicable, haptic alerts;
- ADHD/neurodivergent: reduced stimulation, progressive disclosure, cognitive-load controls;
- PTSD/TBI-sensitive use: intensity controls, safe Shadow/sensitive overlays, no forced exposure;
- reduced motion: alternate transitions preserving spatial identity.

## Non-negotiable rules

- Essential information may not depend only on audio, color, particle motion, depth, or haptics.
- Reduced motion is not a generic blank fallback; it preserves world identity with lower movement/density.
- Focus must remain visible and deterministic on conventional UI controls.
- Canvas/spatial content requires semantic companion controls or equivalent navigation.
- No uncontrolled spinning, sudden scale jumps, or forced cinematic movement without a reduced-motion alternative.
- Sensitive content must have an immediate, understandable exit path.
