# URAI Experience Architecture

Status: CANONICAL RECOVERY BASELINE

## Experience stack

### Layer 1 — Arrival and grounding
Home, Orb, Ground, Passport, onboarding, privacy/permission boundaries.

### Layer 2 — Orientation and exploration
Ascent, Life Map, Galaxy scale, Memory Stars, timeline, search, relationships, places.

### Layer 3 — Intimate attention
Focus, selected-memory context, evidence/provenance, reflection.

### Layer 4 — Reconstruction and meaning
Replay, Mirror, emotional context, narrator/companion reflection, pattern inspection.

### Layer 5 — Difficult/long-horizon reflection
Shadow, Legacy, Council, Rituals, Possible Futures, Scrolls.

### Layer 6 — External continuity
notifications, devices, wearables, EWI, sharing/export, professional/RuAI, institutional systems.

## Core continuity

Primary lineage:
`Home -> Ascent -> Life Map -> Focus -> Replay -> Focus -> Life Map -> Home`.

Ground is a separate grounded realm reachable from Home and returns without replacing the Life Map chain.

Mirror, Passport and secondary realms are controlled branches, not random disconnected pages.

## Scale model

- Cosmic: life system / galaxy / long-range orientation.
- Regional: chapter, relationship, goal, place, emotional region.
- Intimate: one memory, one decision, one reflection, one private chamber.

Camera, sound, UI density and object density change together with scale.

## Experience laws

- user always has orientation and return;
- semantic/direct controls remain available when movement is difficult;
- spatial movement supplements rather than replaces access;
- evidence and interpretation are visibly distinct;
- private/sensitive material is never forced open;
- reduced-motion/stimulation preserves the same experience identity;
- no state fabricates personal evidence simply to stay visually interesting.
