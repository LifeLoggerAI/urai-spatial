# URAI Asset Integration Blueprint

## Folder Structure

```
assets/
  brand/
  environments/
  characters/
  animations/
  audio/
  video/
  demos/
  manifests/
```

## Naming Convention

Format:

`category-purpose-version-state`

Example:

`environment-life-map-v1-approved`

## Image Requirements

- web optimized formats
- multiple resolutions
- accessibility metadata
- documented usage

## Video Requirements

- launch hero video
- product walkthrough
- demo clips
- social variants

Requirements:
- captions
- thumbnails
- transcripts

## 3D Requirements

- optimized models
- materials
- lighting setup
- performance budget
- fallback representation

## Audio Requirements

- ambient layers
- interaction sounds
- narration
- accessibility alternatives

## Generation Prompt Template

Every generated asset includes:

- visual objective
- style direction
- technical requirements
- placement context
- acceptance criteria

## Acceptance Tests

Asset passes when:

- correct format
- correct location
- visually approved
- performance acceptable
- documented
- integrated successfully
