# URAI V1 Product Specification

## Definition

URAI V1 is the verified spatial AI experience foundation.

## Primary User Experience

1. Threshold entry
2. Spatial navigation
3. Life Map exploration
4. Replay and memory interaction
5. Privacy and control understanding

## Demo Structure

Opening:
- explain the experience
- establish trust
- enter the world

Middle:
- show spatial environment
- show memory/life-map concepts
- demonstrate interactions

Closing:
- explain future expansion path
- collect interest

## Public Surface

Public:
- verified experiences
- documentation
- demos
- supported features

Private:
- experiments
- future research
- unverified concepts

## Acceptance Criteria

- build passes
- release checks pass
- routes are verified
- user journey is understandable
- evidence exists for claims

## Asset Integration

Future premium media must plug into existing contracts without changing core architecture.
