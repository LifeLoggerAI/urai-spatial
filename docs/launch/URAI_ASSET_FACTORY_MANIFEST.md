# URAI Asset Factory Manifest

## Purpose

Define every future premium asset before generation begins.

## Asset Record

Each asset requires:

- ID
- purpose
- destination
- format
- dimensions
- integration point
- acceptance criteria
- verification receipt

## Categories

### Environment Assets

Examples:
- worlds
- rooms
- landscapes
- spatial backgrounds

### Character Assets

Examples:
- avatars
- guides
- companions

### Motion Assets

Examples:
- transitions
- camera paths
- effects

### Audio Assets

Examples:
- ambient layers
- sound design
- narration

### Marketing Assets

Examples:
- launch videos
- screenshots
- social content

## Intake Pipeline

1. Generate asset
2. Validate quality
3. Attach metadata
4. Place into manifest
5. Run integration checks
6. Publish with receipt

## Rule

Assets enhance the system; assets do not define the system.
