# URAI AI Self-Ledger V1

Status: launch-convergence source authority.

The Self-Ledger is an auditable activity record, not a consciousness claim and not hidden model reasoning.

It may record externally observable operational facts: authorized evidence references, excluded references and reasons, permission snapshots, provider/model/version, public output references, hashes, corrections, action receipts, and later observed outcomes.

It must never persist hidden chain-of-thought, reasoning tokens, model weights, provider-private internals, revoked evidence, or another user's private world. When a provider is used, exact model/version metadata is mandatory.

Scenario creation and independent outcome observation generate trusted server-side ledger receipts. Client mutation of ledger records is denied by Firestore rules.
