# URAI Possible Futures V1

Status: canonical launch-convergence implementation. Provider generation remains disabled until exact provider/model/version and intelligence release gates are satisfied.

Possible Futures is the user-facing name for URAI Scenario exploration. It lives inside `urai-tier1`, uses `/possible-futures`, reuses the existing world-travel/return stack, and never creates a second runtime.

## Launch behavior

- User-initiated only.
- Maximum three branches.
- Branches are not ranked.
- Every rendered branch remains `truthKind: scenario`.
- No Scenario may write autobiographical memory or observed reality.
- No Scenario may dispatch an external-world action.
- Direct-arrival with no evidence requires explicit assumption-only authority.
- A provider-unavailable state exposes Manual Scenario rather than fabricated AI output.
- Provider evidence IDs must be a subset of the immutable authorized Scenario basis.
- Later outcomes require a new observation or user assertion and never rewrite the historical Scenario.

## Visual truth

Every Scenario surface carries `POSSIBLE FUTURE · NOT A MEMORY`. Scenario geometry may be spatially rich but must remain semantically distinguishable from factual Replay. Literal-pixel acceptance is a separate exact-head release gate.
