## Visual grammar

The system should feel related without turning every subsystem into the same logo.

- **Core shape language:** orbit, field, threshold, constellation, reflection, thread, horizon, pulse.
- **Geometry:** simple enough to survive favicon size; layered enough to animate in spatial UI.
- **Typography:** product name remains primary; glyph is an anchor, not a badge wall.
- **Motion:** marks may breathe, orbit, split, converge, bloom, or resolve. Reduced-motion versions remain fully legible.
- **Color:** runtime/environment context may tint the mark; semantic meaning must never depend on color alone.
- **Depth:** product surfaces may render marks as true 3D objects; launch/press/social derivatives use clean vector/flat equivalents.

## Final-capture replacement rule

Templates are not product evidence. Final product screenshots/video must be captured from one accepted exact release SHA and must retain the SHA, route, viewport, accessibility mode, capture timestamp, and evidence receipt. Generated or mocked UI may never be described as a live product screenshot.

## Spend rule

The deterministic local Asset Factory path is allowed. Paid provider adapters, paid generation, retries, remixes, cloud deployments, new production keys, and protected provider mutations are outside this lane.

## Done definition

This lane is done when every named system has a reusable mark, every named surface has a zero-cost deterministic template, and every template can be replaced by exact-SHA product capture without redesigning the pack.
