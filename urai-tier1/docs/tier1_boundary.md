# URAI‑Spatial Tier 1 Boundary Sheet

Ground‑minimum is in Tier 1. Ground‑expansion is not.

Tier 1 exists to prove the first complete experiential truth of URAI. That means the user must begin somewhere real, leave that place, enter the memory field, focus, replay, and return to a place that still feels physically and emotionally continuous. If that grounded state is missing or fake, Tier 1 is not actually complete.

## Tier 1: required ground‑minimum

1. **Ground as canonical start state**  
   The app opens into a stable home-state, not an abstract loading shell, menu-first UI, or disconnected scene fragment.  

   *Pass:* The user clearly feels “I am somewhere” the moment the app loads.  
   *Fail:* The start state feels like a tech demo, overlay shell, placeholder set, or decorative stage.

2. **Ground as canonical return state**  
   Every trip into LifeMap, focus, and replay must resolve back into the same grounded world in a deliberate, cinematic, emotionally coherent way.  

   *Pass:* Return-home feels like arriving back into the user’s world.  
   *Fail:* Return feels like mode switching, reset, or UI dismissal.

3. **Basic sense of place**  
   Ground must have enough visual structure to feel like a real experiential anchor: spatial depth, horizon/sky relationship, floor/terrain truth, atmosphere, and a readable center of presence.  

   *Pass:* The user can intuit orientation and presence.  
   *Fail:* The ground is just a flat plane or decorative filler with no embodiment.

4. **Camera‑led embodiment on ground**  
   The camera behavior at Home must feel authored and intentional. Idle state, transition out, and return in must all be spatially convincing.  

   *Pass:* Camera motion makes the world feel physically undeniable.  
   *Fail:* Camera is static, arbitrary, floaty, or obviously debug-like.

5. **Home-state continuity**  
   Ground must visually and emotionally connect to the sky/LifeMap system. It cannot feel like a separate product stitched onto the memory field.  

   *Pass:* The user feels that the sky above or space beyond is part of the same world.  
   *Fail:* Home and LifeMap feel like unrelated scenes.

6. **Minimal ambient life**  
   There must be enough motion or atmosphere to prevent the ground state from feeling dead. This can be lighting drift, orb breathing, fog motion, subtle environmental animation, or other restrained ambient behavior.  

   *Pass:* The space feels alive even when idle.  
   *Fail:* The scene feels frozen, empty, or placeholder-like.

7. **Interaction-free readability**  
   Ground must read as real even before the user clicks anything. It cannot depend on labels or dock UI to explain itself.  

   *Pass:* The scene communicates itself visually.  
   *Fail:* The user only understands where they are because UI text tells them.

8. **Tier 1 closure**  
   Ground must complete the emotional loop. After replay, the user should feel they have returned to a lived, stable world-state.  

   *Pass:* There is a real sense of completion.  
   *Fail:* The experience ends in a technically correct but emotionally empty state.

## Tier 1: optional but allowed on ground

These can exist in Tier 1 only if they are restrained and do not destabilize the lock:
- A home silhouette or structure  
- Simple orb/presence anchor  
- Subtle environmental layers  
- Very light symbolic props  
- Minimal atmosphere or parallax  
- One or two carefully controlled visual cues that imply a larger world  

These are acceptable only if they support the canonical loop rather than creating new systems.

## Ground‑expansion: explicitly not required for Tier 1

These belong in Tier 2+ unless already trivial and non-disruptive:
- Free roaming on ground  
- Walkable world systems  
- House interiors  
- Cars  
- Friends/people moving around  
- Council members physically present  
- NPC logic  
- Quests/tasks on the ground  
- Inventory/object ownership systems  
- Deep environmental interaction  
- Ground-based product surfaces  
- Branching scene destinations  
- Simulation of neighborhood/world ecology  
- Fully embodied avatar systems  
- Persistent object relationships  
- Social world logic  
- Animal/pet layers  
- Full “my world” sandbox behavior  

These are expansion systems, not Tier 1 requirements.

## Strict acceptance criteria for Tier 1 ground

Tier 1 ground is complete only if **all** of the following are true:
- The app starts in a believable home-state.  
- The user can leave home without breaking immersion.  
- The user can return home with cinematic continuity.  
- Ground visually reads without explanatory UI.  
- The camera makes the start and return states feel authored.  
- The world has enough ambient life to avoid dead-scene syndrome.  
- Home and LifeMap feel like one system.  
- Replay resolution lands back into ground with emotional closure.  

If any of those fail, Tier 1 is not locked.

## Fast rule for future decisions

Ask one question:  
**Does this improve the first complete experiential loop, or does it introduce a second system?**

If it improves the loop, it may belong in Tier 1.  
If it introduces a second system, it is Tier 2+.  

The cleanest one-line definition is:  
*Tier 1 ground is the minimum believable embodied home-state required to start and close the URAI loop; anything beyond that is expansion.*
