# URAI Launch Checklist

## Build
- pnpm install
- pnpm typecheck
- pnpm build

## Visual QA
- First Light shows ≤ 6 lines
- No orb during First Light
- Smooth transition into Life Map
- Companion appears once after entry
- No flicker or jitter

## Demo
- /demo/life-map route works
- First Light resets correctly
- One clean star interaction

## Trust
- "Why am I seeing this?" present
- No over-interpretation
- Voice silent by default

## Performance
- No infinite loops
- No console errors

## Launch
- Demo video recorded
- Landing page live
- Waitlist capturing emails

## Final rule
Quiet first. Meaning second. Trust always.
