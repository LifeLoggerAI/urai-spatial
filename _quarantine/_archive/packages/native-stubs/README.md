# Phase 6: Native Stacks

As per the `URAI-SPATIAL-PROJECT-CHARTER.md`, native client development (e.g., Unity, visionOS, native ARKit/ARCore) is **explicitly out of scope** for the `urai-spatial` project.

The charter defines the project's boundaries as follows:

> ## What this project DOES NOT OWN (out of scope)
> - **Native Stacks (Unity / visionOS / etc)**
> - The URAI web app frontend
> - The URAI marketing site
> - User identity or auth systems (connects to them)

The focus of this project is the web-based spatial engine, including the runtime, AR/VR systems on the web, and the asset pipeline. Any future native development will be handled as a separate project.
